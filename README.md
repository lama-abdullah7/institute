# موقع معهد نخبة للتدريب والتطوير

صفحة تعريفية (One Page) جاهزة للنشر على GitHub Pages، مبنية بملف واحد `index.html` (بدون أي أدوات بناء أو تثبيت).

## المحتوى الحالي (تقديري — عدّله كما تحب)
- من نحن + اعتمادات (نصوص افتراضية، لازم تستبدلها ببياناتكم الحقيقية)
- 6 دورات تدريبية بأسعار افتراضية
- 3 دبلومات بأسعار افتراضية
- 4 مدربين (بدون صور، أول حرفين من الاسم كأفاتار — تقدر تستبدلها بصور حقيقية لاحقًا)
- ألوان أخضر/أحمر مطابقة تقريبًا للشعار — عدّل قيم `--green*` و `--red*` في أعلى ملف `index.html` (قسم `:root`) لمطابقة درجات شعاركم بالضبط

## كيف تعدّل
كل شي بملف واحد: `index.html`
- **النصوص**: ابحث عن الجملة اللي تبي تغيّرها وعدّلها مباشرة
- **الألوان**: أول ٢٠ سطر تقريبًا داخل `<style>` تحت `:root { ... }`
- **الأسعار/الدورات**: كل دورة بطاقة `<article class="course-card">` مستقلة، انسخ/احذف/عدّل كما تحب
- **الشعار الحقيقي**: استبدل `<span class="logo-mark">` بـ `<img src="logo.png" ...>` بعد ما ترفع ملف الشعار بجانب index.html

## كيف تنشره على GitHub Pages

1. أنشئ Repository جديد على GitHub (public)، مثلاً باسم `nukhba-institute`
2. ارفع محتوى هذا المجلد له (أو استخدم الأوامر التالية من جهازك):
   ```bash
   git remote add origin https://github.com/USERNAME/REPO-NAME.git
   git branch -M main
   git push -u origin main
   ```
3. من صفحة الـ Repository على GitHub: **Settings → Pages**
4. تحت "Build and deployment" اختر Source: **Deploy from a branch**
5. اختر Branch: **main** والمجلد: **/ (root)** ثم **Save**
6. بعد دقيقة أو دقيقتين بيصير الموقع متاح على:
   `https://USERNAME.github.io/REPO-NAME/`
